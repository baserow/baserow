# Quick start with Baserow

This guide will help you get started with using Baserow to organize and manage your data.

In this section, you will learn about the basic building blocks of Baserow. You will also learn how to create your first database. It’s designed to help you get familiar with the user interface and learn about Baserow’s features.

## How does Baserow work?

Baserow allows you to build and edit your data without writing code.

By the end of this section, you will be able to:

  1. Create a new Baserow account
  2. Create and customize workspace
  3. Create a new database
  4. Add tables to your database
  5. Add fields to your tables
  6. Enter data into your tables
  7. Configure views for optimal data representation
  8. Create an application
  9. Collaborate and share

Let’s get started!

## Step 1. Create a Baserow account

> If you have already [installed Baserow or created a cloud account](/user-docs/set-up-baserow), you can skip this section.

Baserow can be configured in two ways, depending on how you intend to use it:

  * [Baserow Cloud](/user-docs/set-up-baserow#baserow-cloud): SaaS offering on the [baserow.io](/) website
  * [Self-hosted](/user-docs/set-up-baserow#self-hosted): Host your own instance on-premise or in the cloud

For this quickstart, we suggest using the Cloud version.

There are a few ways to create a Baserow account. The most common method is to sign up using your name and email.

  * [Create an account directly from the signup page](/signup). Enter your email address, name, and password, and then click on the **Sign up** button.
  * [Sign up by invite from a workspace admin](/user-docs/manage-workspace-permissions)
  * [Sign up for Baserow using Single Sign On (SSO)](/user-docs/single-sign-on-sso-overview)

## Step 2. Create and customize workspace

When you log in to Baserow, you will be redirected to the dashboard. The dashboard is where you can organize and view all your [workspaces](/user-docs/intro-to-workspaces), [applications](/user-docs/application-builder-overview), and [databases](/user-docs/intro-to-databases). It is also the starting point for creating new databases, applications, and workspaces.

You can either:

  * [Set up a workspace from scratch](/user-docs/setting-up-a-workspace)
  * [Add a database to an existing workspace](/user-docs/create-a-database)

Tailor your workspace settings to match your team’s needs and preferences. Adjust permissions and settings to create a personalized workspace environment.

## Step 3. Create a new database

In the sidebar, you can see all the databases in the selected workspace.

Click on the **Create a database** button to start creating your new database. Choose a template or select the “Start from scratch” option if you prefer to build your database from the ground up.

To quickly start using Baserow, use a pre-built template with tables, fields, and views. Baserow templates allow you to work with simulated data.

  * Go to [Templates](/templates/)
  * Search for a template, for example, “Lightweight CRM”
  * Preview and select the CRM template
  * Click on **Use this template** to open the template in your editor

## Step 4. Add tables and fields

The sidebar is made up of applications, and [databases](/user-docs/intro-to-databases), and nested within are your [pages](/user-docs/pages-in-the-application-builder) and [tables](/user-docs/intro-to-tables).

Customize the database by adding additional tables and fields, rearranging them, or setting up any specific configurations to meet your requirements.

Define the fields that will hold the specific data you want to store. You can choose from different field types like text, number, date, file, AI, formula, etc.

  * [Create tables](/user-docs/create-a-table) to organize your data efficiently within the workspace.
  * [Define fields within each table](/user-docs/adding-a-field) to capture and structure your data effectively.

Once you’re done setting up your database structure, you can add rows by clicking on the `+` icon or the **Add row** button. There are other ways to [add a new row in a Baserow table](/user-docs/how-to-make-new-rows).

Fill in the appropriate data for each row, populating the fields based on your database structure. You can always make changes or modifications later as needed.

## Step 5. Populate the table with data

Whether you have data in spreadsheets, JSON format, CSV files, or other formats, you can quickly import existing data from various sources into your workspace. This capability enhances your data management workflow and improves working efficiency with large datasets.

  * [Create a table via import](/user-docs/create-a-table-via-import)
  * [Import data into an existing table](/user-docs/import-data-into-an-existing-table)
  * [Import Airtable to Baserow](/user-docs/import-airtable-to-baserow)

## Step 6. Configure views for optimal data representation

Customize views to visualize and interact with your data in the most meaningful way. Explore different view options, such as [Grid](/user-docs/guide-to-grid-view), [Gallery](/user-docs/guide-to-gallery-view), [Form](/user-docs/guide-to-creating-forms-in-baserow), [Calendar](/user-docs/guide-to-calendar-view), and [Kanban](/user-docs/guide-to-kanban-view) views.

## Step 7. Create an application

Baserow’s Application Builder module is a powerful way to build applications, offering flexible ways to create workflows, visualize data, and tailor information to different audiences across organizations.

The Application Builder allows you to create custom software applications for various purposes, such as building websites, client portals, internal tools, dashboards, and more.

  * [Application Builder overview](/user-docs/application-builder-overview)
  * [Create an application](/user-docs/create-an-application)
  * [Application Builder configuration](/user-docs/application-builder-configuration)

## Step 8. Collaborate and share

Invite team members to collaborate on your Baserow workspace. Set permissions and access levels to ensure secure and controlled sharing of data.

  * [Add Baserow users](/user-docs/manage-workspace-permissions)
  * [Remove Baserow users](/user-docs/remove-a-user-from-a-workspace)
  * [Baserow user permission guide](/user-docs/permissions-overview)
  * [Share a specific view publicly](/user-docs/public-sharing)

Baserow [role-based permissions](/user-docs/role-based-access-control-rbac) provide additional security and control for your data management needs. This feature is exclusively available to users who are subscribed to the Baserow [Cloud Advanced or Self-hosted Enterprise plans](/pricing).
