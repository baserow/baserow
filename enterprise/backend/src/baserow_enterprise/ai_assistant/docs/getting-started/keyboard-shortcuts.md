# Keyboard shortcuts

In this section, we will discuss some of the most useful keyboard shortcuts in Baserow that can help you work quickly and efficiently.

While using Baserow, you may find yourself performing repetitive tasks that can be time-consuming. That’s where keyboard shortcuts come in handy. Keyboard shortcuts are key combinations that allow you to perform a task with a single keystroke or a combination of keystrokes.

## Mac keyboard shortcuts

General |   
---|---  
`Cmd ⌘` `Z` | Undo action  
`Cmd ⌘` `Shift ⇧` `Z` | Redo action  
`Cmd ⌘` `P` | Print the current table view or current expanded record (if inside an expanded record)  
`Cmd ⌘` `Shift ⇧` `S` | Opens search bar  
Grid view |   
---|---  
`Cmd ⌘` `C` | Copy a cell or range of cells  
`Cmd ⌘` `V` | Paste a cell or range of cells  
`→` or `Tab` | Move forth ( R ) between cells in a row  
`←` or `Shift ⇧` `Tab` | Move back ( L ) between cells in a row  
`↑` | Move up between cells in a column  
`↓` | Move down between cells in a column  
`Shift ⇧` `Enter` | Insert a row below the selected cell  
`Enter` or `F2` | Edit the selected cell. (Press `Enter` again to update the cell.)   
Clicking `Enter` on a [file](/user-docs/file-field) will open the file upload window.   
Clicking `Enter` on a [linked field](/user-docs/link-to-table-field) will open the linked table window.   
Clicking `Enter` on a [boolean](/user-docs/boolean-field) field will check/uncheck the cell  
`Esc` | Close an enlarged row  
`Shift ⇧` `Click` | Select multiple cells. Click the first cell in the range, and then hold down `Shift` while you click the last cell in the range  
`Shift ⇧` `↑` or `Shift ⇧` `↓` | Hold down Shift + up/down arrow keys to expand your selection up or down in Grid view  
`Shift ⇧` `←` or `Shift ⇧` `→` | Hold down Shift + right/left arrow keys to expand your selection to the right or left in Grid view  
Space bar | Select a cell then click the space bar to open an enlarged version of a row

## Keyboard shortcuts for the Application Builder

You can navigate and build with [Baserow Application Builder](/user-docs/application-builder-overview) using your keyboard. By using keyboard shortcuts, you can save time and increase your productivity while working in Baserow.

Shortcut |   
---|---  
`Delete/Suppr` | [Duplicate](/user-docs/add-and-remove-elements) the selected element  
`←` or `→` or `↓` or `↑` | Select another [element](/user-docs/elements-overview)  
`Ctrl` \+ `←` or `→` or `↓` or `↑` | Ctrl + arrow keys to move the selected [element](/user-docs/elements-overview)  
`P` | Select a [parent element](/user-docs/elements-overview)  
`C` | Select the first child of the currently selected [container element](/user-docs/elements-overview)
