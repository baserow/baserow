# Install self hosted premium license

A premium license gives you access to all [premium features](/user-docs/subscriptions-overview#how-subscription-works-for-saas-hosted-plans) in the self-hosted version.

This guide covers how to get and register a license on your self-hosted Baserow server to activate the **Premium** subscription. To activate Enterprise license, [refer to this support article](/user-docs/activate-enterprise-license).

## Get your Instance ID

This article covers how to find your Self-hosted Instance ID required to upgrade users to the premium plan if you have installed Baserow on your own server.

To create the license, we need your self-hosted instance ID to upgrade users to another plan. The instance ID is the unique identifier of your Baserow copy. The license will be connected to it.

Only an Instance Admin can access the [Admin panel](/user-docs/enterprise-admin-panel) to retrieve the instance ID required to perform billing actions. Users without staff access do not have access to the entire instance.

Find your Baserow instance ID by logging into your Baserow self-hosted instance as an Instance Admin under: Admin → Licenses → copy the instance ID.

![https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/1952c4ef-9bb5-4523-9db6-23576ec89fd9/Screenshot_2022-08-09_at_13.11.02.png](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/1952c4ef-9bb5-4523-9db6-23576ec89fd9/Screenshot_2022-08-09_at_13.11.02.png)

It is possible to change the instance ID for an ongoing subscription in case you want to use the license for a different instance later on.

## How to get your licence key

After [purchasing a self-hosted subscription](/user-docs/buying-a-subscription#buy-a-subscription-for-the-self-hosted-version), you will be able to download a licence key that will allow you to register your Baserow self-hosted instance. It’s not possible to use the same key on two different installations.

  1. A license can only be obtained on [baserow.io](http://baserow.io/). Log into [baserow.io](http://baserow.io)
  2. Navigate to: Subscriptions → License subscriptions → More details → Reveal license key

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/a99b9d2c-8e15-40e4-91ae-af807761aaa8/Screenshot%202023-01-25%20at%2010.45.58.png)

If you have already purchased a subscription, it will be delivered to you by email and you can get in from the overview in your account.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/2f6af240-80ba-473a-bda2-4d651200d7a2/Screenshot_2022-08-10_at_10.58.58.png)

If you don’t have a key yet, purchase a subscription [and view pricing](/pricing).

## Register a license to a Baserow instance

The [Admin Panel](/user-docs/enterprise-admin-panel) enables instance admins to create access rules and keep an overview of every user license in the company.

If you already have a license, you can register a license to an instance

  1. In your self-hosted instance, navigate to: Admin → Licenses → Register license.

  2. Copy and paste the [license key](/user-docs/get-a-licence-key#how-to-get-your-licence-key) into the field provided and click on the **Register License** button.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/d21486c1-8c2a-4a65-a16b-41f31d11af09/Screenshot_2022-08-10_at_11.01.03.png)

After registering your license, you can assign users to the seats by selecting which registered users will be able to use paid features. These users can then use paid features across all workspaces, while users that are not assigned to the license won’t be able to do so. You can mix free and paid users in one Baserow instance and it doesn’t matter in which workspaces the users will work.

After your license has expired, you and any assigned users will no longer be able to use the extra functionality granted by the license.
