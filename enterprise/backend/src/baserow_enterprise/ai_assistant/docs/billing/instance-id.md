# Get self-hosted Instance ID

This article covers how to find your Instance ID required to upgrade users to the premium plan if you have installed Baserow on your own server.

To create the license, we need your self-hosted instance ID to upgrade users to another plan. The instance ID is the unique identifier of your Baserow copy. The license will be connected to it.

Only an Instance Admin can access the Admin panel to retrieve the instance ID required to perform billing actions. Users without staff access do not have access to the entire instance.

Find your Baserow instance ID by logging into your Baserow self-hosted instance as an Instance Admin under: Admin → Licenses → copy the instance ID.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/1952c4ef-9bb5-4523-9db6-23576ec89fd9/Screenshot_2022-08-09_at_13.11.02.png)

It is possible to change the instance ID for an ongoing subscription in case you want to use the license for a different instance later on.
