## Row comments and mentions

> Commenting on rows is only available in the Premium version only.

Row comments are a feature in Baserow that allows users to add comments or notes to individual rows in a table. These comments can be used to provide additional context, collaborate with team members, or keep track of important information related to specific rows.

## Overview

With row comments, users can easily communicate and share insights directly within the table, promoting efficient collaboration and organization.

By default, the comments panel is visible inside the row edit modal. You can hide it by clicking on a collapse `>>` button in the top right of the expanded row.

## View row comments

To view which rows have comments on them, there will be a number indicator beside the rows that have comments in them, showing how many comments have been made.

![Commenting on Rows](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-15_at_12.53.32.png)

Click on the enlarge row icon to view all the comments that have been made.

![view all the comments that have been made](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-15_at_12.49.48.png)

You’ll see a comment box at the bottom right of the enlarged row where you may start typing to leave a comment. Just above the comment box, you’ll find a feed of any recent comments. To comment on a row, drop a comment in the form on the right side of the enlarged view.

![drop a comment in the Baserow](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-15_at_12.55.17.png)

### Edit row comments

You can edit row comments in Baserow. This feature comes in handy when you accidentally get autocorrected and post a comment that doesn’t accurately convey what you intended.

With Baserow, you can easily edit your comments after posting them, ensuring that you can clarify your true intentions.

To edit a comment that you’ve already posted,

  1. Locate the menu button located on the right side of the comment and click on it.
  2. From there, you’ll see a list of options.
  3. Select the “Edit comment” option that allows you to correct any autocorrected or mistaken comments.

![Row comments in Baserow](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/2821f369-679d-4a8f-8feb-eb73fc90dfa9/baserow%20comments.png)

### Delete row comments

In Baserow, you can delete row comments. This means that if you get autocorrected and post the comment, you can still delete it.

To delete a comment on a row,

  1. Locate the comment you wish to remove.
  2. Click on the menu button located to the right of the comment.
  3. A dropdown menu will appear with various options.
  4. Select the “Delete comment” option that allows you to remove the comment from the row.

By following these steps, you can easily delete row comments in order to ensure that your intended message is accurately conveyed.

## Track comments

You can select to get alerts only when someone mentions you in a comment. Or, you can get alerts for all comments in a row, even if no one mentions you.

If you wish to get alerts for all comments on a certain row, click on the bell icon at the top of the row edit box. This will allow you to follow that row. When you follow a row, you will get alerts every time someone comments on it. This feature helps you keep track of tasks and processes that need your focus.

![Follow or unfollow row comments](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/133f6a9a-fb43-4782-87bb-14bee8bd7d20/Watching%20comments.png)

## Mentions

You can mention your [collaborators](/user-docs/working-with-collaborators) in the comment box. Tagging your collaborators is an effective way to grab their attention and direct it towards specific tasks and projects.

To mention a person in comments,

  1. Type the `@` symbol in the comment box.
  2. Select the user’s name from the dropdown
  3. Click **Enter**.

After the comment is published, the mentioned user will receive a [notification](/user-docs/notifications).
