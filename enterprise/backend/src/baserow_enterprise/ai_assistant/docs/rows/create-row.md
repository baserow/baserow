# Create a row

You need to create new rows to add new data to a Baserow database. In this guide, we’ll walk you through the steps required to make new rows in Baserow, so you can start organizing your data like a pro.

To get an overview of rows and their features, [visit this support article](/user-docs/overview-of-rows).

Here are five methods to add a new row in Baserow:

  * Click the plus button at the bottom of your rows to create a new empty row.
  * Right-click any row and use the menu to insert a new row above or below the selected one.
  * Use the [hotkey](/user-docs/baserow-keyboard-shortcuts) `Shift` \+ `Enter` while navigating with the arrow keys to add a new row below the current row.
  * [Duplicate a row](/user-docs/how-to-make-new-rows#duplicate-a-row) by selecting it, right-clicking, and choosing the “Duplicate” option.
  * [Copy and paste data](/user-docs/paste-data-into-baserow-table) from your clipboard to add new rows. Be cautious, as pasting starts from the selected row and may overwrite existing data.

## Create a blank row

Making a new row on Baserow is simple. There are ways to add a new empty row as a record in your table. Locate the table where you want to add the new row:

  * Click on the plus icon (+) that appears after the last row at the bottom of the view.
  * Right-click on an existing row and select **Insert row above** from the contextual menu.
  * Right-click on an existing row and select **Insert row below** from the contextual menu.
  * Use the [hotkey](/user-docs/baserow-keyboard-shortcuts) `Shift` \+ `Enter` while navigating with the arrow keys to add a new row below the current row.

## Create a row from the row select modal

You can also create a new row directly in a linked table from the row select modal in a [link to table field](/user-docs/link-to-table-field).

To create a new row from the row select modal in Baserow:

  * Within the selected database, locate the table in which you want to create the new row.
  * In a [link to table field](/user-docs/link-to-table-field), click the plus icon (+) to create a relationship with a linked table to open the row select modal.
  * Click on the plus icon (+) that appears after the last row at the bottom of the view.
  * In the row select modal, enter the appropriate data for each field in the form.
  * Once you have filled in all the necessary details for the new row, click on the **Create** button in the row select modal.
  * The new row will be created in the linked table and added as an option in the table.

## Duplicate a row

To duplicate a row in Baserow, follow these steps:

  * Open the table view that contains the row you want to duplicate.
  * Locate the row you wish to duplicate then click on the row to select it.
  * Once the row is selected, right-click on the row to open the row options menu.
  * From the menu, select the **Duplicate row** option.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/acaa68fc-b94e-4eea-8230-1f53f4fa2eb5/Screenshot%202022-07-22%20at%2014.30.50.png)

Baserow will create a duplicate of the selected row and place it immediately below the original row.

## Create multiple rows using right-click

  * Log in to your Baserow account.
  * Navigate to the desired database where your table is located.
  * Locate and click on the name of the table you want to work with. The table will open, displaying the existing rows and columns.
  * Right-click anywhere on the row. A context menu will appear.
  * Click on the row number to select the number of rows to create

## Edit or modify a new row

If you need to make any changes to the new row after it has been created,

  * Locate the row in the table.
  * Click on the cell you want to edit.
  * Make the necessary changes and click outside the cell to save the modifications.
