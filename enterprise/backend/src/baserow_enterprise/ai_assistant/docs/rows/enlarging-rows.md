# Enlarge rows

Enlarging rows in Baserow allows you to view and work with more detailed information within a row without cluttering the main table view.

![Enlarging rows](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-28_at_22.58.41.png)

To enlarge a row in Baserow,

  1. Open your Baserow workspace and navigate to the desired table.
  2. Locate the row you want to enlarge.
  3. Look for a small icon on the left side of the row.
  4. Click on the icon to enlarge the row.

![To enlarge a row in Baserow](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/2230602e-5ffa-49a2-a65e-e34efc91a5d6/Screenshot%202023-07-18%20at%2014.14.17.png)

## Inside an enlarged row

Once a row is enlarged, you will be able to view and access any additional information or fields associated with that row.

When working with an expanded row in Baserow, you have the option to [add a new view](/user-docs/create-custom-views-of-your-data). You also can access the [row comments](/user-docs/row-commenting) on the right side of the page.

If there are hidden fields within your table, these will also be hidden in the enlarged view.

![Inside an enlarged Baserow row](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/f07e465e-861f-413c-acfd-4e6295b6f741/Edit%20values.png)

You can directly edit the values of linked rows from the row edit modal. Any changes you make to the row will be reflected in the original table. No need to switch between tables just to modify or add information to a linked row.

## Collapse an enlarged row

To collapse the enlarged row, click on the `X` icon.

![Inside an enlarged view](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/553aac6ba5c1ed35ad98130e257b9b2bb0c4864b.webp)
