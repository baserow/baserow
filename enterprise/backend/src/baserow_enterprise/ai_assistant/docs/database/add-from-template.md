# Add database from template

The easiest way to get started if you are new to Baserow is to copy a [template](/templates/). To start with a template, you first need to choose a workspace into which the template will be installed.

You can add a template in two ways:

  1. From the template page, or
  2. From your dashboard.

## From the template page

One way to add a template to a workspace is from the [template](/templates/) page. From our library of templates, you can select a pre-made template that is designed specifically for your use case.

In this case, we will use the Blog Post Management template.

  1. Select the template from the 50+ options across various categories.
  2. Click on **Use this template**.
  3. Select an existing Workspace or create a new workspace where the template will be installed into
  4. Click the **Create** button.

You can customize the template to suit your needs.

## From the dashboard

To add a new database from the dashboard

  1. Click the **\+ Create new** button in the workspace you want to add the database to
  2. Select **From template** from the dropdown options.
  3. Select a template from the 50+ option across various categories.
  4. Click on **Use this template**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-14_at_19.45.27.png)

You can alternatively [create a database from scratch](/user-docs/create-a-database) or [import a database from Airtable](/user-docs/import-airtable-to-baserow).
