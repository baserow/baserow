# Delete a database

Want to start over? You can delete your database. If you need to delete your database for any reason, you can start over again with a new database.

To delete a database:

  * In the right sidebar, click the `⋮` icon next to a database.
  * Select **Delete database**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-13_at_15.07.43.png)

Within 5 seconds after deleting the database, you can undo this action by clicking the button at the bottom right of the screen.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-15_at_10.26.34.png)

Learn more about the [undo/redo function](/user-docs/data-recovery-and-deletion).

## Snapshots

Snapshots provide a full copy of a database, making it possible to restore a database to that point in time later on. By using a snapshot, you can make backups and protect yourself against accidental loss.

To create, restore or delete a snapshot, click on the icon to reveal the database menu and select the Snapshot option from the dropdown.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/592b6b22-9a15-46cd-bbdd-9393608722b8/SNN%20snapshot.png)

## View trash

You accidentally deleted a database? No worries! All deleted items stay in the trash for 3 days, after which they’re permanently deleted.

The Trash function within Baserow allows you to restore deleted items from the past 3 days. After 3 days, your data is deleted permanently and can no longer be restored.

To view the database trash:

  * Click the vertical ellipses `⋮` icon in the right corner next to the database you want to delete in the sidebar.
  * From the pop-up menu, select **View trash**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot%25202022-06-15%2520at%252010.19.28.png)

Learn more about [restoring data from the trash](/user-docs/data-recovery-and-deletion).
