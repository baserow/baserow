# Create a database

Baserow makes it easy for anyone to create a database that fits their specific needs. Whether you are managing a project, tracking inventory, or organizing customer data, Baserow provides a user-friendly platform that allows you to easily store, organize, and manipulate your information.

In this section, we will walk you through the steps of creating your own Baserow database. Baserow offers multiple ways to get your project up and running:

  * Create a database from scratch.
  * [Create a database from a template](/user-docs/add-database-from-template).
  * Make a copy of an existing database in Baserow.
  * [Import a database from Airtable](/user-docs/import-airtable-to-baserow).

## Add a new database from scratch

You can create a database in any workspace from scratch. To create a new blank database within a workspace:

  1. Click **\+ Create new**.
  2. Select **Database** from the dropdown option.
  3. Enter a name for the new database. When you create a database, be sure to give it a descriptive name. You can subsequently change the descriptive name as needed.

## Duplicate a database

To duplicate a database, you need to hover over the database and click on the three dots `⋮` icon next to a database. Select the **Duplicate database** option from the dropdown. You can view the database and database duplication progress in the left sidebar.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/b506539d-1121-42a2-b021-43aa79a30d3e/Screenshot%202022-07-27%20at%2016.57.57.png)

## Rename database

To rename a database:

  * In the right sidebar, click the `⋮` icon next to a database.
  * Select **Rename database** and enter a new name for the database.
