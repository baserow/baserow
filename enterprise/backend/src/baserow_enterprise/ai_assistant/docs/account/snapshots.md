# Snapshots

Snapshots provide a reliable way to protect and manage your database effectively.

Snapshots are complete copies of a database that allow you to restore it to a specific point in time. They are essential for backing up your data and safeguarding against accidental loss.

## Overview

> Creating, restoring, listing, and deleting snapshots require an [Admin](/user-docs/permissions-overview) role.

A snapshot will include any permissions set on the application and its tables.

To perform these actions, simply click on the database menu icon, select the Snapshot option from the dropdown menu, and choose the desired action.

## Cancel snapshot

Job cancellation for snapshots allows you to cancel ongoing snapshot jobs. This offers control over the snapshot process, particularly for large databases where creating snapshots might be time-consuming.
