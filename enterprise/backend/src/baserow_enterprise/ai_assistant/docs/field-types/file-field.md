# File field

File field enables users to add a wide range of multimedia files to their rows. This field type allows users to attach images, videos, audio files, and documents directly to their database, providing a central location for all the related files. The file field is incredibly flexible and can be used in a variety of ways, from storing product images to project-related documents, making it an invaluable tool for businesses, teams, and individuals alike.

In this section, we will dive deeper into the Baserow file field.

Learn more about how to use [AI file support in Baserow](/user-docs/ai-field).

## Add a file field

To add a new field,

  1. Click on the `+` button located just after the last visible field, or insert a new field to the left or right of an existing field.
  2. When prompted to select a field type, choose the “File” field as the desired field type.
  3. Give the new field a descriptive name. This could be something like “Uploaded File,” “Attachment,” or a name relevant to the kind of files users will be uploading.
  4. Once you’ve configured the field settings. Click on the **Create** button to finalize the process and save your changes.

Note that you cannot sort rows with a file field.

## Uploading files to a table

Click the plus (+) button on the cell to which you want to add a file to or click the **Add a file** button in the enlarged row to upload a file to the file field. Selecting this option will bring up a dialog box in which you can select one or more files.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/8c1c00a8-2256-4b46-bf42-5d45e60ae48a/Screenshot_2022-07-13_at_19.31.55.png)

This allows you to upload a single file or multiple files at once.

### Upload from a device

You can upload from your device by:

  * dragging and dropping files into the file uploader dialog
  * Click to select the files

You can upload files stored on your computer or from websites by clicking **my device** and using the dialog to upload a file from your computer.

Additionally, you can drag and drop files directly into the individual or expanded cells.

### Upload from a URL

You can upload files from a URL by pressing the button labelled **a URL** , pasting the URL into the field and clicking **Upload**.

## Customise individual files

When viewing multiple files in an enlarged row, click the edit, download, or delete icon. When you see the pencil icon in the expanded view, you can click it to rename the file.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/f4f979c3-5e49-4e7d-9af2-e16b2958f6ac/Screenshot_2022-07-13_at_21.01.53.png)

Alternatively, click on the icons to download each file separately when viewing a single file in the full-screen file previews. The pencil icon appears at the top of the screen while in view. The trash bin and download icons appear at the bottom right of the screen.

## Supported file types

Baserow supports different types of files depending on how you access Baserow. Any file type can be uploaded into a file field, however, only some of them can be previewed.

  * Image and design files (.png, .heic, .jpg, .webp, .gif, .svg, .psd, and .tiff file formats)
  * Word documents (.doc and .docx)
  * Excel files (.xls, .xlsx, and .csv)
  * Text files (.txt)
  * PDF documents (.pdf)
  * Powerpoint presentations without embedded videos (.ppt and .pptx)
  * Audio and Video files (.mp3, .mp4, .webM, and .ogg / .ogv files)
  * XML data (.xml)

## Preview files

When you upload a file, Baserow will generate a preview containing a small thumbnail image of the file.

For the image and design file types, thumbnails are created as a preview of the file.
