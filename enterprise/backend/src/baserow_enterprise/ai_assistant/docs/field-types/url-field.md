# URL field

The URL field allows users to add hyperlinks to external resources directly into their databases. Users can easily link to web pages, documents, images, and other types of media, making it easier to keep track of related information in one place. Each cell in a URL field is designed to hold a single URL. You can access a URL by clicking on it.

## How to add a URL field

To add a URL field,

  1. Click the plus sign + to the right of your existing fields.
  2. Select the URL field type and input the name of the field.
  3. Click ‘**Create** ’
