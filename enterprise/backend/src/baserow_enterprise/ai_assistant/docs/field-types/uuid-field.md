# UUID field

The UUID field in Baserow automatically generates a unique identifier for each row. This field is often used as a primary key to uniquely identify each row in a table.

## Overview

The UUID field in Baserow automatically assigns a unique number to each new row. Users cannot manually change the unique values, ensuring data integrity. They are automatically generated and cannot be edited.

![UUID field](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/0208b9af-752b-4cd2-990f-543541f6003b/UUID.png)

## Add a UUID field

To add a UUID field,

  1. Click the plus sign `+` to the right of your existing fields.
  2. Select the UUID type and name the field. You can add a unique field name in the customization menu.
  3. Click **Create**.
