# Boolean field

A boolean field is a useful way to store true/false values in a row. The field represents information in a binary true/false format. For example, when a task is completed, you can tick the “Done” boolean field in a task tracking table.

## How to add a boolean field

To add a boolean field,

  1. Click the plus sign + to the right of your existing fields.
  2. Select the boolean field type and input the name of the field.
  3. You can optionally set the default state to true or false
  4. Click ‘**Create** ’
