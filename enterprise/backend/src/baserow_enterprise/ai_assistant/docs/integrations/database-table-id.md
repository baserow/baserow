# Database and table ID

Automate your workflows efficiently and streamline your processes with Baserow.

Baserow is a versatile tool that allows users to connect their data with various apps and services. By leveraging Baserow’s API and webhooks, users can automate their workflows and integrate their data with other software seamlessly. This simplifies the process of managing and organizing data, enabling businesses to save time and streamline their operations.

## Find your database ID

If you need to find your ID, the URL in your browser’s address bar will look something like the following: `https://baserow.io/database/30143/table/69215`

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-05-27_at_10.42.23.png)

## Find your table ID

You can also find your Baserow table ID by clicking on your account in the top left corner -> Settings → Database tokens → your token → show databases.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-07-04_at_15.28.41.png)

Also, find your Baserow table ID by clicking on the three dots next to the table. It’s the number between brackets:
