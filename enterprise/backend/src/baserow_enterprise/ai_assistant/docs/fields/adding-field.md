# Create a field

This support article covers how to add a new field. For an overview of field types supported in Baserow, including how to format your data and use it effectively, refer to this [article on Baserow fields](/user-docs/baserow-field-overview).

## Set up a field

To create a new field, you can click on the `+` button just after the last visible field at the end of the table. Next, select the field type and input a name to identify the field. Click **Create**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot%202022-07-12%20at%2011.45.16.png)

## Field description

Field descriptions provide clarity and improve collaboration by specifying the type of data expected in each field.

To add a field description:

  1. Open the table containing the field you want to describe and navigate to the field.

  2. Click on the field name. This will display a dropdown menu to access the field settings.

  3. Within the modal window, click the **\+ Add description** button.

  4. A text box will appear where you can enter a clear and concise description of the data expected in this field.

A well-written description should be specific and informative. Here’s an example:

Field name: “Project Name”

Description: “Enter the full and official name of the project.”

  5. Once you’ve entered your description, click the **Save** button located at the bottom of the modal window.

The description will now be displayed alongside the field name, providing valuable context to anyone using your Baserow table.

## Duplicate an existing field

To duplicate a field, click on the arrow-down icon next to a field. Select the **Duplicate field** option from the dropdown.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/f5a4647e-8d4e-49bb-abc1-92b7feee7288/Screenshot%202022-07-27%20at%2017.07.07.png)

While duplicating a field, you can choose either to duplicate it with or without data. To duplicate a field, click on the arrow next to the field name, select the duplicate field option from the dropdown and put a checker mark if you want it to be duplicated together with data.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/41498ea7-e896-43f6-9181-614caadb0dac/Untitled\(25\).png)

## Insert a new field

> Note that you cannot insert a new field from the [Primary field](/user-docs/primary-field).

To add a new field, you can either use the + button at the end of the table or insert a new field between existing fields. You can select a field and either insert a new field to the left or right of that field. Learn more about [reordering and moving fields](/user-docs/field-customization).

To insert a new field,

  1. Click on the dropdown icon next to the field you want to insert a new field beside the existing field.
  2. Select either **← insert left** or **→ insert right**.
