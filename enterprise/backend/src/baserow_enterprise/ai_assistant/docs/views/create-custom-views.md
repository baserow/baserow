# Create custom views of your data

This section provides a guide to view your work as a Grid, Gallery, Form, Kanban, and more — toggle views instantly to bring clarity and perspective to your projects.

Visit this support section to [learn more about views in general](/user-docs/overview-of-baserow-views). You may find our help section on [sharing views](/user-docs/public-sharing) useful.

![Create custom views of Baserow data](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-20_at_15.10.50.png)

## Add a new view

When you first create a table, your default view will be the Grid view. After this, you can create additional views at the top left of the table, with the + button.

To create a new view,

  1. From the top of the table, select the view switcher at the top of the table to reveal the view dropdown. If this is a new table, the current view will be the `≡ Grid` view.
  2. The options will appear in the View menu at the top of your screen. Go down to the second half of the view dropdown
  3. Select a view type from the options presented for the type of view you’d like to create.
  4. Click on a view type to open up the menu to create your new view. Choose the [view permission type](/user-docs/collaborative-views) and give this view type a name. We recommend giving each view a unique name if you have more than one view in the table.
  5. Click ‘**Add view’**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/a9007150b3c81d47840366908a5214573b01ebad.webp)

Once you’ve added your new view, you can [customize, show/hide fields, filter rows](/user-docs/view-customization) out of it, adjust the width of each column, or sort the rows and columns.

> Note that the [kanban view](/user-docs/guide-to-kanban-view) is restricted to the premium version only. Users on the free plan cannot create a kanban view.

## Switch between views

The current view tab in the table’s upper left corner helps in navigating all of the table’s views. You can switch between different view types in a table by clicking the view switcher in the upper left corner. Then click on the view to switch to the target view.

![Switch Baserow view](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/a2ffbd1a-9059-49a2-87ba-1d621830b6ec/Switch%20view.webp)

## Search existing views

If you created a lot of views in your table, it might be helpful to locate a view by name. Existing views can be found by searching for them using the views search bar.

  1. Click the View switcher dropdown
  2. Enter a search string in the ‘**Search views** ’ field to locate a view
  3. You can enter a search term to see a list of all views that match.
  4. Select the view to navigate to
