# Collaborative views

This section provides a guide to Collaborative views. To learn more about views in general, check out this [support article](/user-docs/create-custom-views-of-your-data).

You can choose from the two view permission types:

  1. Collaborative views: Collaborative views are visible and configurable by all [workspace members](/user-docs/working-with-collaborators).
  2. [Personal views](/user-docs/personal-views): Personal views are only visible to the user creating them.

You can change the view type from collaborative to personal or vice versa. Simply click on the ellipsis ••• next to the desired view and select the option to change the view type.

## Create new collaborative views

Collaborative views are the default permission type for new tables.

![Create new collaborative views](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/cacbb156-2d99-48f5-84a1-0496ec16797b/Screenshot%202023-03-07%20at%2018.07.38.png)

If you want to select a different view permission type, [create a new view](/user-docs/create-custom-views-of-your-data). Click on the “+” button next to the preferred view. Simply select a view permission type option before clicking “Add view”.

To learn more about personal views please [see this support article](/user-docs/personal-views).

It is possible for all members owner of the workspace to configure a collaborative view. Every user with the right permission can edit collaborative views. It is visible to other members of the workspace by default.
