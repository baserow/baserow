# Import a workspace

We understand how important it is to have flexibility when managing your data. Whether you’re moving between instances, sharing information across workspaces, or simply creating a backup for safekeeping, importing workspaces can streamline the process.

This guide walks you through how to import entire workspaces in Baserow, helping you seamlessly transfer or copy your data with ease.

## Overview

If you’ve been using one Baserow instance for a specific project and now need to move it to another instance for broader collaboration, or you’re consolidating multiple workspaces into a central location. You might even be creating an offline backup, ensuring your critical data is safe and stored securely outside of the current Baserow environment. In all these cases, importing workspaces ensures your data is transferred quickly and without the risk of losing any important information.

With the Baserow import feature, you can replicate your workspace, including its tables, rows, and configurations, into any Baserow instance. This not only saves time but also ensures consistency in your data management practices.

> It’s not possible to import a zip file from an untrusted source.

## How to import a workspace

Before importing, make sure your workspace file is ready. You’ll need a [compatible export file](/user-docs/export-workspaces) from another Baserow instance. If you haven’t exported your data yet, be sure to do so first. Exporting workspaces creates a file that captures everything you need for a seamless import.

To have your workspace up and running in no time:

  1. Navigate to the Home page on your Baserow dashboard. This is your central hub for managing your workspaces.
  2. Locate the workspace where you’d like to import your data. Next to the workspace name, you’ll notice a small arrow icon. Go ahead and click on that. A dropdown menu will appear with several options.
  3. In the dropdown menu, look for and select the option labeled ‘Import data’. This will open a new interface where you can upload the file that contains the workspace data you wish to import.

Once the import is complete, your workspace will appear alongside your other workspaces in the Home page. You’ll be able to access it, edit it, and share it just like any other workspace. Everything, from your tables and rows to configurations, will be exactly as it was in the original workspace.
