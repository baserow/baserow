# Leave a workspace

Looking to change things up? It’s easy to leave a workspace you are in.

When you leave a workspace you won’t be able to access the related applications anymore. Note that the workspace will not be deleted as other collaborators will still have access to it. To regain access to the workspace, one of the workspace admins must invite you to the workspace again.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-15_at_12.42.08.png)

## Leaving a workspace as the last admin

If you are the last workspace admin in a workspace, you will not be able to leave as this action will leave the workspace unmaintained. We suggest assigning workspace admin permission to another collaborator within the workspace before you leave the workspace.

The actions below should be followed if you are the last admin in the workspace and want to leave without deleting the workspace:

  * Make another collaborator a workspace admin on the **Members** settings page.
  * Then they will be able to add people to the workspace and manage collaboration.

Alternatively, you can consider deleting the workspace. This option is also suggested if you want to leave a workspace but you do not want other collaborators to have access to it after you leave.
