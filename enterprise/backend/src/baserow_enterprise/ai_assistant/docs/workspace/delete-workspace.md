# Delete a workspace

> Only a [workspace admin](/user-docs/working-with-collaborators) can delete a workspace.

You can permanently delete a workspace from your settings if you decide that it is no longer needed.

To delete a workspace:

  * Switch to the workspace you want to delete from the Dashboard or by using the sidebar.
  * Click the vertical ellipses `⋮` icon in the right corner next to the workspace name.
  * Click **Delete workspace**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/7a05fd16-d96c-4922-9901-dbf958109719/07703903-e4dc-47a4-8b7f-521b7b73fecb.webp)

You can [recover the deleted workspace from the trash](/user-docs/data-recovery-and-deletion) if you change your mind. Note that you cannot restore deleted items after 3 days of deletion. Deleting a workspace is permanent and there is no way to recover any data after the 3-day period.

If you no longer require the workspace, you can [leave the workspace](/user-docs/leave-a-workspace) and transfer ownership to another workspace admin as an alternative to removing it.

## View trash

To view the workspace trash:

  * Click the vertical ellipses `⋮` icon in the right corner next to the workspace you want to delete in the sidebar.
  * From the pop-up menu, select **View trash**.
