# Set up a workspace

Learn the basics and create your workspaces. Applications like databases belong to a workspace, so in order to create databases or tables, you must first create or be invited into an existing workspace by a workspace administrator.

In this section, we’ll cover how to set up your Baserow workspaces.

## Create a workspace

With Baserow, creating a new workspace is simple, so here’s how you do it. With just one click of the plus button (+), you can create your workspace. There are two ways to create a new workspace from the dashboard.

  1. On the dashboard main page click the **\+ Create workspace** button. This button will also be visible on the sidebar.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/b169fcba251d61f1860882c33330bb478fd22e4d.webp)

  2. Additionally, if you have existing workspaces you can also create a new workspace by clicking the vertical ellipses `⋮` icon in the right corner next to the Workspace name. This will take you to the dropdown for your list of workspaces. Click the button **\+ Create workspace**.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-08_at_22.11.52.png)

You’ll be required to give a new workspace a name when it has been created. Name the workspace to represent whatever you are working on, from managing team activities or tracking the progress of a product launch to project management or structuring internal processes and workflows. It’s helpful to give each workspace a name that describes its content.

You can rename a workspace after it’s created or at any time.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-07-01_at_13.20.16.png)

When you create a new workspace, you automatically take on the role of [workspace admin](/user-docs/working-with-collaborators). After you’ve created a workspace, you can add databases and tables to it and invite collaborators to join.

## Workspace settings

To access the workspace settings in Baserow, follow these steps:

  * In the sidebar, hover over the workspace. You will see a small vertical ellipsis `⋮` (three dots) appear by the workspace.
  * Click on the ellipsis ⋮ to open the workspace options menu.

## Rename a workspace

> This action is restricted to [workspace admins](/user-docs/working-with-collaborators) only.

To rename a workspace:

  * Switch to the Workspace you want to manage from the dashboard or by using the sidebar.
  * Click the vertical ellipses `⋮` icon in the right corner next to the Workspace name
  * Click **Rename Workspace**.

## Troubleshooting

### I created a new account in the self-hosted plan but I can’t create a new workspace. What should I do?

If you are unable to create a new workspace in the self-hosted plan, you should contact the Instance Admin.

If the option to “Allow everyone to create new workspaces” is disabled by the Instance Admin, newly created accounts that are not invited as collaborators in an existing workspace will not have the ability to create a workspace. In such cases, you need to reach out to the Instance Admin for assistance.

### What does “Instance Admin” mean in the context of a self-hosted instance?

In a self-hosted instance, the Instance Admin is the person responsible for setting up and managing the instance. They have administrative privileges and can control various settings and permissions within the platform.
