# Delete a table

There may be instances when working with Baserow data that you need to remove a table from your database. Existing records in a table can be deleted using the Baserow delete option.

![enter image description here](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot%25202022-06-14%2520at%252009.57.17.png)

## View trash

If you accidentally delete a table, you will have three days to recover it from your account trash. The Trash function within Baserow allows you to restore deleted items from the past 3 days. After 3 days, your data is deleted permanently and can no longer be restored. Before deleting a table, take care. The entire data contained in a table will be lost if it is permanently deleted!

To view the database trash, click **Trash** in the home screen sidebar under the dashboard to access the trash. This will bring up a list of the deleted data from the past three days.

Learn more about [restoring data from the trash](/user-docs/data-recovery-and-deletion).
