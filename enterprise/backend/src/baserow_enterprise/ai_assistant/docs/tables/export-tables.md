# Export a table

In this section, you’ll learn how to export tables from Baserow.

You can download data from a table by accessing the table menu, and then choosing a specified export format encoding. You can sync and back up your data by exporting it to another database. The export will contain all field values that are present in the view, except the [row comments](/user-docs/navigating-row-configurations).

![Select the Baserow table to export](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/b2c54e0e-85c6-45fd-a243-d1e1fb845a67/Select%20the%20table%20to%20export.webp)

## Supported file formats

Export file formats include:

  * Comma-separated values (CSV),
  * Extensible Markup Language (XML),
  * JavaScript Object Notation (JSON),
  * Excel to download the data in .XLSX format.

You can export either an entire table or [a specific view](/user-docs/overview-of-baserow-views). This provides a simple way to convert your data for use in other tools.

![Image: Baserow export to Excel](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/34c782a5-9d60-4307-b646-033a875a9b02/excel_export.webp)

## How to export a table

You can export a table or a view. To export a table:

  * In the right sidebar, click the `⋮` icon next to a table.
  * Select **Export table**.
  * Choose **Export entire table** to download the entire data on the table or [select a view](/user-docs/overview-of-baserow-views) from the dropdown menu to export that view.
  * Click the file format you want to export and download the file.

![eHow to export a Baserow table](https://baserow-backend-production20240528124524339000000001.s3.amazonaws.com/pagedown-uploads/Screenshot_2022-06-14_at_09.54.48.png)

After you export the table, the file you download will be found in your device’s default download folder.
