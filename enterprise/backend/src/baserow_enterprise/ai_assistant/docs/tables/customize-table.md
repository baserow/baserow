## Rename a table

You can rename a table to make it simpler to refer to it, for instance, in a database that contains several tables. Renaming a table can be useful if the table is part of a database that contains many similar tables or to make its purpose clear.

To rename a table:

  * In the right sidebar, click the `⋮` icon next to a table.
  * Select **Rename** and enter a new name for the table.

## Webhooks

Webhooks allow you to receive real-time notifications about changes in your database, like new rows, updates to existing rows, or rows moving in or out of views.

To get more details about [webhooks and how they work](/user-docs/webhooks), read this section.

## Multiple cell paste

You can copy and paste multiple cells. Hit the `Cmd/Ctrl` \+ `V` command and voila, data is inserted in seconds.
